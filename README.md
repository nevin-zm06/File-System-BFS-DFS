# File System Representation and Search Using BFS and DFS

## Aim
Represent a file system as a graph using an adjacency matrix and search it using Breadth-First Search (BFS) and Depth-First Search (DFS).

## Description
Each node represents a file or directory. An edge represents a connection between two nodes. The program reads an adjacency matrix, a starting node, and a target node. It displays the traversal order and whether the target node was found.

For this simple demonstration, nodes are represented by numbers from `0` to `n-1`, not by actual file names.

## How to run
Compile `main.c` with a C compiler, then run the program and enter:
1. Number of nodes
2. The adjacency matrix
3. Starting node
4. Target node
